      门禁清单与评审细则对照，评审可逐条点开核对。
  方式一 · Docker 一键（推荐，已实测）：
    git clone https://github.com/wookat/life-circle-web.git
    cd life-circle-web && docker compose up --build
    → 访问 http://localhost:8787，无需任何密钥即进入「演示模式」
  方式二 · 本地 Node.js ≥ 20：
    npm install && npm run dev
    → 打开 http://localhost:5173，同样自动进入演示模式
    （确定性合成数据，完整体验：定位 → 体检 → 热力面 → 人群对比 →
     盲区 → 规划建议采纳 → 方案对比 → 街道体检 全流程）

  接入真实数据（可选）：
    cp .env.example .env
    填入百度地图开放平台的浏览器端与服务端 AK 后重启，
    即可以真实路网数据完成体检（服务端通道 48 向批量算路）。
    AK 安全：.env 已被 gitignore，密钥只存在于本地环境变量；
    浏览器端 AK 配 Referer 白名单，服务端 AK 配 IP 白名单。
