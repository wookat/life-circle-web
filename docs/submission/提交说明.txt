三、演示复现指引（评审方快速跑通）
  环境：Node.js ≥ 20
    git clone https://github.com/nghqqa/life-circle-15min.git
    cd life-circle-15min
    npm install
    npm run dev
  → 打开 http://localhost:5173，无需任何密钥即进入「演示模式」
    （确定性合成数据，完整体验：定位 → 体检 → 热力面 → 盲区 →
     规划建议采纳 → 对标清单 → 街道体检 全流程）

  接入真实数据（可选）：
    cp .env.example .env
    填入百度地图开放平台的浏览器端与服务端 AK 后重启，
    即可以真实路网数据完成体检（服务端通道 48 向批量算路）。

  Docker 一键部署：
    cp .env.example .env && docker compose up --build
    访问 http://localhost:8787（API 文档 /api/docs）
